# Shader Usage Analyzer 过滤功能需求

## 目标

在 TA Art Tools 的 Shader Usage Analyzer 中增强 Shader 过滤结果展示，方便只定位使用指定 Shader 的对象和材质槽，并降低命中对象内无关 Shader 槽位带来的查找噪音。

## 功能要求

- 工具面板提供 `结果过滤 Shader` 字段，用户通过 Shader 对象精确过滤结果。
- `自动勾选过滤shader的材质` 按钮放在 `结果过滤 Shader` 同一行，位于过滤附加控件右侧。
- `自动勾选过滤shader的材质` 按钮左侧提供 `显示非过滤 Shader 槽位` 复选框。
- `显示非过滤 Shader 槽位` 默认关闭；过滤启用时，默认只显示命中过滤 Shader 的材质槽。
- 勾选 `显示非过滤 Shader 槽位` 后，命中对象内的全部材质槽都会显示，方便查看同一对象的材质上下文。
- 过滤为空时保持现有全量扫描、显示和替换行为。
- 过滤生效时，只显示至少一个材质槽使用目标 Shader 的扫描对象。
- 结果摘要、报告和 Foldout 标题基于当前可见槽位统计，并标注过滤命中槽位数量。
- `自动勾选过滤shader的材质` 只勾选使用当前过滤 Shader 的可编辑材质槽。
- 过滤生效时，`替换勾选材质 Shader` 只处理当前可见槽位中的已勾选材质；隐藏槽位不参与替换。
- `替换目标材质` 字段用于指定 URP 包内默认 Lit.mat 引用的替换材质。
- `将默认 Lit 引用替换为目标材质` 按钮保持原有引用替换行为。
- 提供 `清除过滤` 按钮，恢复全量显示。

## 非目标

- 不做 Shader 名称模糊搜索。
- 不持久化过滤状态或槽位显示开关。
- 不修改 Runtime、URP、Shader、材质或 RenderFeature 配置。
- 不增加 Shader keyword 或 variant。

## 验证要求

- 无过滤时扫描结果与原行为一致。
- 过滤指定 Shader 后，只显示包含该 Shader 的对象。
- 默认过滤状态下，命中对象内只显示命中过滤 Shader 的材质槽。
- 勾选 `显示非过滤 Shader 槽位` 后，命中对象内显示全部材质槽。
- 无命中时显示空结果提示。
- 过滤状态下批量替换只统计并处理当前可见槽位中的已勾选材质。
- `替换目标材质` 字段和 `将默认 Lit 引用替换为目标材质` 按钮文案正确。
